# Blog Section Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Markdown-powered tech blog to the portfolio, with a `/blogs` card-grid listing, `/blogs/<slug>` post pages with a sticky TOC, full SEO/RSS, an image-prep script, an AI authoring template, and a Blog link in the home page's contact section.

**Architecture:** Posts are `.md` files in `content/blogs/`. A build-time loader (`src/lib/blog/posts.ts`) validates frontmatter, and a unified/remark/rehype pipeline (`src/lib/blog/markdown.ts`) turns bodies into HTML plus a heading list. App Router server components read them during `next build` (static export). Thin client components add view transitions, TOC scroll-spy, code copy buttons, and the lightbox. Pure helpers build metadata, JSON-LD, and RSS. Node scripts using `sharp` handle images.

**Tech Stack:** Next.js 15.4 App Router (static export), React 19, TypeScript, Tailwind 4, framer-motion, html-react-parser (already a dependency). New: `gray-matter`, `unified`, `remark-parse`, `remark-gfm`, `remark-rehype`, `rehype-slug`, `rehype-autolink-headings`, `rehype-external-links`, `rehype-pretty-code`, `shiki`, `rehype-stringify`, `unist-util-visit`. New dev deps: `vitest`, `sharp`.

**Spec:** `docs/superpowers/specs/2026-10-26-blog-design.md`

**Base branch:** `upgrade/next`. `src/constants/site.ts` has an uncommitted, user-requested change (`SITE_URL` default → `https://riyaz-ahmed.com`). Task 1 commits it.

## Global Constraints

- Static export must keep working: `output: "export"` and `images.unoptimized: true`. No server runtime, no runtime data fetching.
- The domain comes only from `SITE_URL` in `src/constants/site.ts` (`https://riyaz-ahmed.com`, domain root). Never hard-code it in code. Template prose may mention it.
- Routes: `/blogs`, `/blogs/<slug>`, `/blogs/rss.xml`.
- Drafts (`draft: true`) are visible only in `next dev`. They must never appear in a production build's listing, post pages, sitemap, or RSS. Sitemap and RSS exclude drafts in every environment.
- Blog pages must not use the home page's loader, Lottie, or `BackgroundAnimator`. framer-motion entrance animations and `useViewTransitionRouter` transitions are fine.
- Styling uses the existing theme tokens: `bg-background` (#333333), `text-foreground`, `accent` (#00d2ff), `accent-secondary` (#ff2a6d), `muted`. Copy the `/projects` header and card classes for consistency.
- All Markdown is rendered at build time. There's no client-side highlighter, and raw HTML inside Markdown is never rendered (no `allowDangerousHtml`).
- Blog images are `.webp`, at most 1600px wide. The build warns, but doesn't fail, on non-`.webp` files or files over 500 KB.
- Author is always `"Riyaz Ahmed"`.
- Post bodies never contain an H1. `##` and `###` feed the TOC.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Zero published posts in production** (only the sample draft exists at launch): `npm run build` must succeed, `/blogs` shows the "coming soon" empty state, and the RSS feed is valid with no items. Next's static export rejects an empty `generateStaticParams`, so this breaks by default. Pinned in Task 7 Step 5 and Task 8.
2. **Frontmatter exactly as the template ships:** empty strings (`updatedAt: ""`, `coverImage: ""`) and unquoted YAML dates (which `gray-matter` turns into `Date` objects) must parse as "absent" and `"YYYY-MM-DD"`. Pinned in Task 1.
3. **Dates off by one day for visitors west of UTC:** `"2026-11-12"` must display as `Nov 12, 2026` in every timezone. Pinned in Task 3, run under `TZ=America/Los_Angeles`.
4. **Special characters in titles and descriptions** (`&`, `<`, `"`, `</script>`): the RSS must stay well-formed and the JSON-LD must not be able to close its `<script>` tag. Pinned in Task 3.
5. **iPhone HEIC or corrupt photos in the raw folder:** the image script skips the file with a message telling the author to export as JPEG, still converts the rest, and exits non-zero. Pinned in Task 4.

## Shared types (defined in Task 1, used everywhere)

```ts
// src/lib/blog/types.ts
export interface BlogPostMeta {
  slug: string;
  title: string;
  description: string;
  publishedAt: string;        // "YYYY-MM-DD"
  updatedAt?: string;         // "YYYY-MM-DD"
  tags: string[];             // lowercased
  coverImage?: string;        // site path, e.g. "/images/blogs/<slug>/cover.webp"
  coverAlt?: string;
  draft: boolean;
  readingTimeMinutes: number;
}
export interface BlogPost extends BlogPostMeta { body: string } // raw Markdown body
export interface TocHeading { id: string; text: string; depth: 2 | 3 }
export interface RenderedPost { html: string; headings: TocHeading[] }
```

### Task 4: Image scripts

**Files:**
- Create: `scripts/lib/og-image.mjs`, `scripts/blog-images.mjs`, `scripts/blog-prebuild.mjs`
- Test: `scripts/__tests__/blog-images.test.ts`
- Modify: `package.json` (`"blog:images": "node scripts/blog-images.mjs"`, `"prebuild": "node scripts/blog-prebuild.mjs"`)

**Interfaces:**
- Produces:
  - `writeOgImage(input: string, ogPath: string): Promise<void>`: 1200×630 JPEG, `fit: "cover"`, quality 85
  - `processBlogImages({ rawDir, outDir, maxWidth = 1600, quality = 80 }): Promise<{ written: string[]; skipped: { file: string; reason: string }[] }>`. Every `.jpg/.jpeg/.png/.webp/.heic/.heif` file becomes `<name>.webp`, resized only if wider than `maxWidth` (never upscaled). A file named `cover.*` also produces `og.jpg`.
  - `ensureOgImages({ contentDir, publicDir }): Promise<string[]>`: for each post with `coverImage`, writes `public/images/blogs/<slug>/og.jpg` if it's missing or older than the cover, and returns the paths it wrote.
  - `findImageWarnings(dir: string, maxBytes = 500 * 1024): string[]`: recursive scan of `public/images/blogs`, ignoring `og.jpg`.
  - CLI `blog:images <slug>`: `rawDir = content/blogs/raw/<slug>`, `outDir = public/images/blogs/<slug>`. Prints each written or skipped file. Exits 1 if the raw dir is missing (with a message naming the expected path) or anything was skipped.
  - CLI `prebuild`: runs `ensureOgImages` then prints each warning prefixed with `⚠`. Never exits non-zero for warnings.
